# 🌍 JM Viagens

Site fictício institucional para a empresa **JM Viagens**, localizado em Ipojuca - PE. O projeto foi desenvolvido com **HTML5**, **CSS3** e **Bootstrap 5**, focando em responsividade, organização de layout e boa usabilidade.

---

## 🌐 Páginas do Projeto

### 🏠 index.html
- Página inicial com imagem de destaque (`principal.png`)
- Menu de navegação para outras páginas
- Parágrafo introdutório sobre a empresa
- Rodapé com tooltip e link do autor

### 👤 quemSomos.html
- Logo substituída por `quem_somos.png`
- Explicação institucional fictícia sobre a empresa
- Menu com links para "Home" e "Contato"
- Rodapé com tooltip (Bootstrap)

### 📬 contato.html
- Logo substituída por `contato.png`
- Tabela com informações de:
  - Localização (Ipojuca-PE)
  - E-mail de contato
  - CNPJ fictício
- Rodapé com link para o LinkedIn do autor
