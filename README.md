# Sua Rotina - Gerenciador de Tarefas Simples
- Este projeto é um simples gerenciador de tarefas que permite adicionar itens a duas listas: uma ordenada e outra não ordenada. Ideal para organizar sua rotina diária.

# Funcionalidades:
- Adicionar tarefas a uma lista ordenada e uma lista não ordenada.
- Validação de entrada: impede a adição de tarefas em branco.
- Interface intuitiva e fácil de usar.
## Como usar:
- Clone o repositório: git clone <link_do_repositorio>
- Abra o arquivo index.html em seu navegador.
- Digite sua tarefa no campo de texto e clique em 'Adicionar'. A tarefa será adicionada a ambas as listas.
- Pressione Enter no campo de texto para adicionar a tarefa rapidamente.
- Tecnologias Utilizadas:
- HTML
- CSS
- JavaScript
